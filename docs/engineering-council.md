# OLYMPUS Engineering Council

The Engineering Council is a catalog-backed internal organization for developing AGENT//FACTORY itself. It is created through the same OLYMPUS organization model as any other local organization.

## Roster

| Responsibility | Catalog role |
| --- | --- |
| Principal architecture | `solution_architect` |
| Backend engineering | `backend_engineer` |
| Frontend engineering | `frontend_engineer` |
| Security engineering | `security_engineer` |
| Risk management | `risk_manager` |
| AI governance | `ai_governance_manager` |
| QA and testing | `qa_test_engineer` |
| Performance engineering | `performance_engineer` |
| Documentation | `documentation_writer` |
| Release engineering | `release_manager` |

Codex is the coordinating architect for the local workflow, not an OLYMPUS member and not an automatic approver. If delegated execution is unavailable, the workflow is explicitly single-agent execution with structured review stages.

## Required workflow

Every substantial council task follows:

```text
DISCOVER → PLAN → CHALLENGE → APPROVE → IMPLEMENT → TEST → REVIEW → REPAIR → VERIFY → RELEASE
```

The runtime does not treat organization membership as permission to execute. Role runtime status, tool allowlists, approval records, plan hashes, budgets, cancellation, and the kill switch remain authoritative.
